# Student Analyzer

## Overview

Student Analyzer is a beginner Python data-processing project developed as Practical 01 in my personal Python Projects repository.

The purpose of the project is to take raw student data from a text file, process each student record, calculate basic statistics, assign a performance grade, and produce a readable report.

This project was intentionally developed from scratch as a learning exercise. The focus was not on memorising Python syntax, but on developing the ability to break a problem into smaller steps and use Python to solve each step.

---

## Problem

A text file contains student names and their marks.

For example:

```text
Thabo,78
Lerato,64
Mpho,91
Naledi,55
```

The program must read the data and produce useful information about the students.

---

## Requirements

The program should:

1. Read student records from an external text file.
2. Separate each student's name and mark.
3. Convert marks from text into numbers.
4. Calculate the total number of students.
5. Calculate the average mark.
6. Determine the highest mark.
7. Determine the lowest mark.
8. Assign a performance grade based on the student's mark.
9. Store the transformed student records.
10. Display the processed student information in a readable format.

### Grading system

| Mark     | Grade |
| -------- | ----- |
| 90–100   | A     |
| 80–89    | B     |
| 70–79    | C     |
| 60–69    | D     |
| Below 60 | F     |

---

## Input

The input file is:

```text
Data/students.txt
```

Each line represents one student.

The format is:

```text
Name,Mark
```

Example:

```text
Thabo,78
Lerato,64
Mpho,91
Naledi,55
```

---

## Processing

The program follows this general process:

```text
students.txt
     ↓
Read one line
     ↓
Remove whitespace/newline
     ↓
Split name and mark
     ↓
Convert mark to integer
     ↓
Determine grade
     ↓
Store transformed student record
     ↓
Update statistics
     ↓
Display results
```

The transformed student record is stored as a tuple containing:

```text
(name, mark, grade)
```

These tuples are stored inside a list.

## Key Learning

The most important concept from this practical was understanding iteration.

For example:

```python
for line in students:
```

means that the file is processed one line at a time.

The project also introduced the idea of an accumulator:

```python
total += mark
```

Instead of calculating the total from scratch for every student, the program maintains a running total as it processes each record.

Another important concept was transforming raw data into a more useful structure:

```text
Raw record:
Thabo,78

Transformed record:
("Thabo", 78, "C")
```

This introduced the idea that a program can take raw data, process it, and create a new representation that is easier to work with.
