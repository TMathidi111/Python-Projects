# Python Projects

A collection of small Python projects built from scratch to develop practical programming and problem-solving ability.

## Philosophy

This repository is not intended to be a collection of syntax exercises.

Each project starts with a practical problem and requires me to:

1. Understand the problem.
2. Break it into smaller problems.
3. Determine what data is required.
4. Find appropriate resources.
5. Build the solution.
6. Test and debug it.
7. Document what I learned.
8. Reflect on what could be improved.

The projects progressively increase in complexity and are designed to develop skills relevant to software development and data engineering.

## Learning Approach

AI is used as a tutor, debugging assistant and assessment tool rather than as the primary developer.

Where AI is used, the project documentation records how it contributed to the learning process.

External documentation, tutorials and developer tools are also used where appropriate.

The objective is to develop the ability to solve unfamiliar problems independently rather than memorise Python syntax.
